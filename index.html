Instalar en Android

Abre la dirección HTTPS de esta app en Chrome y elige Instalar aplicación o Añadir a pantalla de inicio en el menú ⋮. Después de la primera carga podrás consultar tu biblioteca sin conexión.

Tu biblioteca es local

Las canciones se guardan en este navegador y dispositivo. No se sincronizan entre teléfonos. Usa Respaldar para descargar una copia JSON antes de borrar datos o cambiar de teléfono.

Importar y revisar

Importa texto .txt para una canción o un respaldo .json para varias. Las canciones importadas quedan por revisar; no sustituyen las existentes. Revisa el contenido, capo y afinación y pulsa Aprobar canción.

El afinador

Necesita permiso de micrófono y una conexión HTTPS (o localhost durante el desarrollo). El audio se analiza en el dispositivo, no se guarda. Al salir del afinador o esconder la app, el micrófono se apaga.
